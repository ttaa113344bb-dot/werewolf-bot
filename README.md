# بوت المستذئب (Werewolf) لتليجرام

نسخة تعمل بفكرة @werewolfbot: لعبة جماعية داخل مجموعات تليجرام فيها
مستذئبون، عرّاف، طبيب، وقرويون — بدورة ليل/نهار ونقاش وتصويت.

## 1) إنشاء البوت والحصول على التوكن
1. افتح محادثة مع [@BotFather](https://t.me/BotFather) في تليجرام.
2. أرسل `/newbot` واتبع التعليمات (اسم البوت + username ينتهي بـ bot).
3. سيعطيك BotFather **توكن** شكله مثل: `123456:ABC-DEF1234...`
4. عطّل خصوصية المجموعات حتى يقرأ البوت الأوامر:
   أرسل لـ BotFather الأمر `/setprivacy` → اختر بوتك → `Disable`.

## 2) تشغيل البوت محليًا (اختبار سريع)
```bash
pip install -r requirements.txt
export BOT_TOKEN="التوكن_هنا"      # على ويندوز: set BOT_TOKEN=...
python main.py
```

## 3) الاستضافة المجانية 24/7

أسهل خيار حاليًا هو **Render.com** (خطة Free):

1. ارفع هذا المجلد إلى مستودع GitHub جديد.
2. سجّل دخول في [render.com](https://render.com) واختر
   **New → Web Service** واربطه بمستودع GitHub الخاص بك.
3. الإعدادات:
   - Environment: **Python 3**
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `python main.py`
   - Instance Type: **Free**
4. من تبويب **Environment**، أضف متغير:
   - `BOT_TOKEN` = التوكن الذي أخذته من BotFather
5. اضغط **Create Web Service** وانتظر حتى ينتهي الـ Deploy.

⚠️ ملاحظة مهمة: خطة Render المجانية "تُنيّم" الخدمة تلقائيًا بعد حوالي
15 دقيقة من عدم وجود أي طلب HTTP. لإبقاء البوت مستيقظًا 24 ساعة:
1. افتح [UptimeRobot](https://uptimerobot.com) (مجاني) وأنشئ حساب.
2. أضف Monitor جديد من نوع **HTTP(s)** يستهدف رابط خدمتك على Render
   (مثال: `https://your-bot.onrender.com`) بفاصل زمني 5 دقائق.
   البوت يحتوي بالفعل على سيرفر فحص صحّي بسيط (`/`) لهذا الغرض.

**بدائل أخرى** إن أردت تجربتها:
- **Railway.app** — يعطي رصيد تجريبي مجاني شهريًا، ولا يحتاج حيلة الإيقاظ.
- **Fly.io** — طبقة مجانية محدودة للتطبيقات الصغيرة.
- **PythonAnywhere** — مناسب لسكربتات بسيطة لكن أقل ملاءمة للبوتات الدائمة التشغيل.

في كل الحالات: البوت هنا يعمل بوضع **Polling** (لا يحتاج Webhook ولا
شهادة SSL خاصة)، لذلك إعداده على أي منصة تقريبًا هو نفس الخطوات:
ثبّت المتطلبات، ضع متغير البيئة `BOT_TOKEN`، شغّل `python main.py`.

## 4) طريقة اللعب داخل المجموعة
1. كل لاعب يفتح محادثة خاصة مع البوت ويضغط **Start** (ضروري لاستقبال دوره السري).
2. داخل المجموعة: `/newgame` لإنشاء لعبة، ثم `/join` للانضمام.
3. عند اكتمال 4 لاعبين على الأقل: منشئ اللعبة يكتب `/startgame`.
4. تبدأ دورة الليل (أفعال سرية بالخاص) ثم النهار (نقاش + تصويت علني)
   وتتكرر حتى يفوز أحد الطرفين.

## 5) الأوامر
| الأمر | الوصف |
|---|---|
| `/newgame` | إنشاء لعبة جديدة في المجموعة |
| `/join` | الانضمام للعبة الحالية |
| `/leave` | الانسحاب قبل البدء |
| `/players` | عرض قائمة اللاعبين المنضمين |
| `/startgame` | بدء اللعبة (لمنشئها فقط) |
| `/stopgame` | إلغاء اللعبة الحالية |

## تخصيص اللعبة
في أعلى `main.py` يوجد:
```python
MIN_PLAYERS = 4
NIGHT_SECONDS = 45
DISCUSSION_SECONDS = 60
VOTE_SECONDS = 40
```
عدّلها حسب رغبتك، وأيضًا دالة `build_roles()` للتحكم بعدد المستذئبين
ومتى يظهر دور الطبيب.
